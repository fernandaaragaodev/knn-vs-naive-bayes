# 📝 Comparação de Algoritmos de Machine Learning

Atividade acadêmica desenvolvida em Python para comparar os algoritmos K-Nearest Neighbors (KNN) e Naive Bayes utilizando a base de dados Iris. Foram realizados testes com diferentes valores de K e validação cruzada (5-fold), analisando a acurácia média e o desvio-padrão dos modelos.

## 🛠 Tecnologias e Ferramentas

⚙️ Scikit-learn  
💻 Python  
📊 Pandas | NumPy  
🧪 Machine Learning | Cross-Validation
